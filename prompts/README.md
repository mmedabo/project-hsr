# Evolta Prompt Library

The "Prompts" tab of the AI Company OS — reusable, copy-paste prompts for each
department. Use them to kick off common tasks fast and consistently.

**How to use:** open the file for the department, copy a prompt, fill the
`{{placeholders}}`, and paste it to that department's agent (e.g. *"Have the
marketing agent: <prompt>"*). Every agent still reads `company/PROFILE.md`
first, so keep that current.

| File | Department |
|------|------------|
| `ceo.md` | Strategy, goals, prioritization |
| `engineering.md` | Build, debug, ship |
| `marketing.md` | Content & growth |
| `sales.md` | Leads & pipeline |
| `finance.md` | Numbers & cash flow |
| `support.md` | Customer success |
| `operations.md` | Systems & workflows |
