# Engineering — Prompt Library

### Build a feature
> As Evolta's engineering agent, implement {{feature}}. Confirm the approach and
> trade-offs first, match our stack/conventions, add tests, and report how to
> run it.

### Debug
> We're seeing {{bug/error}}. Reproduce it, find the root cause, fix it, and add
> a regression test. Explain what was wrong.

### Review
> Review the changes on this branch for correctness, security, and tech debt.
> List issues by severity with concrete fixes.

### Ship
> Prepare {{change}} for release: checklist, CI steps, rollout, and rollback
> plan.
